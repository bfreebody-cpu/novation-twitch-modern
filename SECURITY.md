# Security and hardware safety

Please report security-sensitive issues privately to the repository owner rather
than opening a public issue with exploit details.

This project controls USB hardware and can produce audio. Do not run experimental
audio tools with speakers or headphones at normal listening levels. Begin with
MASTER, BOOTH, and headphone levels down and powered speakers off.

Never publish signing certificates, private keys, provisioning profiles, Apple
team identifiers, personal capture paths, or unredacted system diagnostics.

The project will not use SIP disablement, reduced-security boot, ad-hoc DriverKit
activation, or execution of legacy Novation binaries as supported workarounds.
