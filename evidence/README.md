# Public evidence policy

This directory contains summaries only. The private research archive retains
raw descriptor bytes, USB transfer JSONL, sustained packed-audio captures,
IORegistry snapshots, and operator logs. Those artifacts are excluded because
they total hundreds of megabytes and include machine-specific state.

Published machine-readable evidence:

- `control-inventory/twitch-basic-input.json`
- `control-inventory/twitch-basic-output.json`
- `control-inventory/controller-v1-led-verification.json`
- `reference/linux/MANIFEST.md`
- `reference/mixxx/MANIFEST.md`

The public status documents retain run IDs, counts, pass/fail decisions, and
measured interpretations. Raw evidence can be reviewed privately when needed to
validate a focused contribution.
